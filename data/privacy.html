Privacy Policy

Last updated: 29 September 2026

MiniCDN is a local simulator of a content delivery network. This page describes what the code in this repository actually does with data. It is a plain description, not legal advice, and it does not claim that the project meets the requirements of any particular law.

Who is responsible

No company or registered business is named for this project. For questions about this policy or the data it describes, contact the project owner at priyanshu23456singh@gmail.com.

What the project handles

MiniCDN does not have accounts, sign-in, forms, or payments, and it does not ask for names, email addresses, phone numbers, or ID numbers. The only inputs are:

  • A city name (from a fixed list) and a file name, sent through the command-line menu or the POST /request API. They are used to choose the nearest edge server and to look up the file in the simulated cache.
  • Simulation results (edge server, cache hit or miss, simulated latency, status), used for the analytics report and charts.

Earlier versions of the API accepted an optional client_name. It served no purpose and has been removed. If a caller still sends it, it is ignored and not stored.

Where data goes and how long it stays

  • Analytics are held in memory and disappear when the program stops.
  • Each request adds one line to logs/server.log on the machine running the program: timestamp, city, file name, edge server, cache status, latency, and status. The log rotates at about 1 MB and keeps three older files, so the oldest entries are dropped automatically. There is no time-based deletion. Delete the logs/ folder to remove it all.
  • Charts in docs/charts/ contain only aggregate totals.
  • When the optional Flask API runs, its development server prints each request's source IP address, time, and URL path to the terminal. The project does not save this output.

Sharing with third parties

The project sends nothing to any third party. It loads no external scripts, fonts, images, videos, or maps, and includes no analytics or advertising tools.

Cookies and similar technologies

The project sets no cookies and does not use localStorage or sessionStorage. Because nothing non-essential is used, there is no cookie banner.

Children

The project does not ask for anyone's age and is not designed to collect personal data from children.

If you run this for other people

The API has no authentication and is meant for local use only. Anyone who deploys it publicly becomes responsible for deciding which privacy rules apply, updating this page, and setting their own retention period and contact details.
